
`../deploy/README.md`, which covers creating `kit-env.sh` and `kits.txt` from the
shipped templates.

## Source of truth: Google Docs

**Every document in this directory is an exported snapshot. The editable
originals live in Google Docs.**

Edit in Google Docs and re-export. Changes made to the Markdown here are
overwritten by the next export and will be lost. The Markdown exists so the
material renders on GitHub, stays diffable, and can be reviewed alongside the
code — not because it is the editable copy.

Document URLs are deliberately omitted: this repository is **public**, and a URL
to a link-shared document effectively publishes it. Ask the camp lead for access.
